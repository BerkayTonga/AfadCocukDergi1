## Oyunlar

1. **Bilgisayarsız Kodlama** (`bilgisayarsiz_kodlama.html`) — Algoritma ve programlama mantığını öğreten interaktif oyun.
2. **Çengel Bulmaca** (`cengel_bulmaca.html`) — Afet ve acil durum terimlerini öğreten bulmaca.
3. **Tahliye Planı** (`tahliye_plani.html`) — Acil durum tahliye planı oluşturma simülasyonu.
4. **Resfebe** (`resfebe.html`) — Görsel ipuçlarıyla kelime bulma oyunu.
5. **AFAD Dergi** (`afad_dergi.html`) — PDF tabanlı interaktif dergi görüntüleyici.

## Teknolojiler

- HTML5, CSS3, JavaScript
- Bootstrap 5, Font Awesome 6
- PDF.js, jQuery

## PDF Dosyaları

- `afad_dergi.pdf`: Derginin kalite kaybı olmadan sıkıştırılmış kopyası (hızlı yükleme).
- `afad_dergi_orijinal.pdf`: Derginin orijinal tam sürümü.

## Ses Dosyaları

Müzik ve efektleri değiştirmek için aynı dosya adlarını kullanarak mevcut dosyaların üzerine yazın:

- Bilgisayarsız Kodlama: `bk_music.mp3`, `bk_wrong.mp3`, `bk_correct.mp3`
- Çengel Bulmaca: `cb_music.mp3`
- Resfebe: `rf_music.mp3`
- Tahliye Planı: `tp_music.mp3`, `tp_correct.mp3`
- AFAD Dergi: `page_flip.mp3`, `loading.mp3`
